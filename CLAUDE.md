# VI Days Mammography Agent Overview

## Project Context
Mammography is a specialized X-ray imaging technique used to screen for breast abnormalities, while breast cancer risk prediction models use imaging and patient data to help estimate an individual’s likelihood of developing breast cancer.

## Starting Task
Perform breast cancer risk prediction based on the AsymMirai model on selected mammograms that are publicly available.

## Ambitious Goal
Build **AsymView**, a simple web app or GUI that uses the AsymMirai model to analyze mammography studies and present breast asymmetry risk predictions in an easy-to-read dashboard. Users can upload or select a de-identified sample study, run inference, and view the model score alongside clear visual indicators and a research-only disclaimer.
